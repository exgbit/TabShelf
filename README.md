# TabShelf - 标签收藏集

免费开源的 Toby 替代品：保存/恢复标签组、新标签页工作台、全局搜索。数据纯本地，支持导出/导入 JSON 跨设备迁移。

![新标签页工作台](screenshots/workbench.png)

## 背景

Toby 早就转成付费了，之前也一直没再续费。[Kimi K3](https://www.kimi.com/) 发布后想拿一个真实需求测测它的编码能力，就把「做一个 Toby 替代品」这个想法捡了起来，覆盖它最核心的几个能力：保存/恢复标签组、新标签页工作台、全局搜索。

项目主体代码由 Kimi K3 开发，效果还不错。

## Toby 是什么

[Toby](https://gettoby.com/) 是一款标签页管理浏览器扩展，用组织（Organization）→ 空间（Space）→ 收藏集（Collection）三级层级来整理保存的标签，并接管新标签页做成可视化工作台，方便按项目/主题保存和恢复一组标签。早期完全免费，后来转向订阅付费，云端账号同步等能力都在付费范围内（具体定价以官网为准）。

## 与 TabShelf 的对比

| | TabShelf | Toby |
|---|---|---|
| 价格 | 免费开源 | 订阅付费 |
| 数据存储 | 纯本地 `chrome.storage.local`，不联网、不用注册账号 | 需要账号，数据存云端 |
| 组织 / 空间 / 收藏集层级 | 支持，且可直接导入 Toby 导出的 JSON（TabShelf 沿用了这套数据模型） | 支持 |
| 新标签页工作台 | 支持 | 支持 |
| 拖拽排序 / 手动添加链接 | 待实现（见「已知限制」） | 支持 |
| 团队协作、跨设备云同步等进阶能力 | 不做，见 [REQUIREMENTS.md](REQUIREMENTS.md)「明确不做」 | 支持（付费功能） |

简单说：TabShelf 只覆盖了 Toby 里保存/恢复标签组、工作台、搜索这几个最常用的核心功能，用「免费 + 纯本地」换掉了订阅费和云同步；如果需要团队协作、跨设备云同步，Toby 官方版本仍是更合适的选择。

## 安装

1. 打开 Chrome，访问 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录
4. 新标签页即变为工作台；点击工具栏图标可保存当前窗口标签

## 功能

- **Toby 风格四栏工作台**：组织图标栏 → 空间面板 → 收藏集卡片区 → OPEN TABS 实时窗口标签列表
- **保存标签组**：点击扩展图标保存单个标签/整个窗口，或工作台右栏 OPEN TABS 中每个窗口的保存按钮一键存为收藏集
- **恢复**：收藏集分区头部「打开全部」在新窗口恢复整组，或点击单个卡片打开
- **组织/空间**：收藏集带两级归属，左栏按组织、空间筛选；空间自动从收藏集归属中派生
- **收藏集管理**：重命名、删除、移动到空间、复制收藏集、复制全部链接到剪贴板、星标置顶、单个折叠或一键展开/收起全部
- **单个标签管理**：单独打开、删除
- **搜索**：工作台顶部搜索框支持快捷键 `/` 聚焦、`Esc` 清空，同时过滤已保存卡片和当前打开的标签；弹窗内搜索框过滤空间和收藏集
- **导出/导入**：JSON 格式，导入时可选择合并或覆盖；支持直接导入 Toby 官方导出的 JSON（保留组织/空间层级）

## 数据与隐私

所有数据仅保存在浏览器本地（`chrome.storage.local`），不联网、不上传、不收集任何数据。跨设备迁移通过导出/导入 JSON 文件完成。

## 已知限制

拖拽排序、手动添加链接暂未实现，见 [REQUIREMENTS.md](REQUIREMENTS.md) 里程碑 M2。

## 更新日志

- **2026-08-02** 修复组织（Organization）重复的 bug：新建空间/收藏集时，默认组织的展示名「个人」被错误地当成真实组织值存了进去，导致收藏集分裂到不同的组织桶里、组织切换器里出现多个重复的「个人」。现在会正确区分「未设置组织」和「组织名字面上叫个人」，并自动合并历史数据中已产生的重复项。
- **2026-07-27** 首次发布：标签组保存/恢复、Toby 风格四栏工作台、组织/空间筛选、全局搜索、JSON 导出导入（兼容 Toby 官方导出格式）。发布前修复了导入功能缺少 URL 协议校验（可能被恶意 `javascript:`/`data:` 链接利用）和并发写入互相覆盖丢数据的问题。

## 文件结构

- `manifest.json` — Chrome MV3 配置
- `popup.html/js/css` — 工具栏弹窗（保存标签）
- `newtab.html/js/css` — 新标签页工作台（浏览/搜索/导入导出）
- `storage.js` — 数据层（chrome.storage.local）
- `REQUIREMENTS.md` — 需求文档

需求与设计决策见 [REQUIREMENTS.md](REQUIREMENTS.md)。
